## Executive Overview

This repository hosts the venture intelligence platform, empirical research base, and detailed engineering blueprints for the institutional initiative: **“One Institution – One Startup”** at a B.Tech Engineering College in **Jagdalpur, Bastar Division, Chhattisgarh**.

Rather than presenting generic hackathon tropes (such as generic smart dustbins, attendance apps, or basic AI chatbots), this platform delivers **20 highly curated, research-backed, physically demonstrable startup ventures**. Each venture is engineered to solve a severe, documented ground problem in Bastar and Central India, buildable by undergraduate engineering students on accessible component budgets (₹4,500 to ₹13,500), and commercially viable with multi-crore public and private market pull.

## Installation & Quickstart

### Prerequisites
- Python 3.9+ (Python 3.10 recommended)
- `pip` package manager

### Setup
```bash
# Clone the repository
git clone https://github.com/your-org/bastar-innovate.git
cd bastar-innovate

# Install dependencies
pip install -r requirements.txt

# Or install as an editable package
pip install -e .
```

### Streamlit Web Dashboard
Launch the modern presentation web dashboard for college faculty and competition juries:

```bash
# Launch via Streamlit
streamlit run run_dashboard.py

# OR launch directly with python
python3 run_dashboard.py
```

The web dashboard features:
1. **🌳 Bastar Ecosystem**: Local geographic, demographic, and ground challenges via `st.metric` cards and structured expanders.
2. **🚫 Eliminated Concepts**: Detailed pre-screening rejection dossiers explicitly highlighting **fatal flaws in red warnings**.
3. **💰 Funding Pathways**: Comprehensive grants explorer across central, state, and CSR schemes with search, tags, and summary metrics.
4. **🚀 20 Curated Ventures**: Master portfolio with interactive sector and budget filters, prototype specs, and flagship blueprints.

### CLI Commands
The platform also includes a terminal CLI tool (`bastar-innovate`):

```bash
# List all 20 curated startup ventures
bastar-innovate list

# Filter ventures by sector or maximum prototype budget
bastar-innovate list --sector healthcare
bastar-innovate list --max-budget 8000

# View complete 18-part dossier for a specific venture
bastar-innovate detail hemopoint
bastar-innovate detail mahuashilp

# Rank ventures across different criteria
bastar-innovate rank --by composite
bastar-innovate rank --by prototype_feasibility --top 5
bastar-innovate rank --by social_environmental_impact --top 5
bastar-innovate rank --by competition_potential --top 5

# View detailed engineering blueprint & BOM for top flagships
bastar-innovate blueprint hemopoint
bastar-innovate blueprint ferroclear

# Head-to-head comparison of two ventures
bastar-innovate compare hemopoint mahuashilp

# Match eligible Indian government grants (PRAYAS, BIG, DMF, MSME)
bastar-innovate grants hemopoint
bastar-innovate grants conveyorguard

# View unit economics and 3-year pro-forma income statement
bastar-innovate financials hemopoint

# View the 5 rejected ideas and elimination rationale
bastar-innovate eliminated

# Display Bastar regional demographic and industrial context
bastar-innovate context

# Export data assets
bastar-innovate export --format json -o data/export_ideas.json
bastar-innovate export --format csv -o data/summary.csv
bastar-innovate export --format docs -o docs/
```

## Institutional Significance for Bastar Engineering College

By focusing on authentic regional problems—from **minor forest produce value capture** to **iron ore conveyor safety** and **point-of-care tribal diagnostics**—a B.Tech student team in Jagdalpur achieves three decisive competitive advantages in national competitions:
1. **Authentic Ground Access**: The student team can physically test prototypes with Bastar tribal SHGs, Jagdalpur Mandi inspectors, and NMDC engineers 20 minutes from campus—a capability no metropolitan IIT team can replicate.
2. **Direct Public Funding**: The venture immediately qualifies for Bastar District Mineral Foundation (DMF) grants, Invest Chhattisgarh seed funds, and regional NMDC CSR capital.
3. **National Hackathon Winning Edge**: When pitching before Smart India Hackathon (SIH), DST NIDHI-PRAYAS, or BIRAC juries, demonstrating a real physical device solving an acute Indian challenge with real field test data creates an unbeatable impression.
